# 反爬与渲染页抓取（天信每日日报）

> **核心立场**：**"页面正文取不到"不是"这个字段没有"，而是"抓取方式不够"。**
> 2026-11-03 路桥误报的根因就在这里——政采云详情页正文由 JS 从接口拉取，WebFetch 只拿到标题，于是预算/截止被判为"未披露"，最终把一条**已过期半个月、预算 50 万、截止 2026-07-22** 的死单当成活单推送。
>
> **纪律**：正文取不到时，**必须**按本文链路升级抓取手段。**只有全部手段都失败，才允许判"无法核验"并剔除**，且须在运行记录写明试过哪几级。

---

## 一、升级链路（按顺序，前一级失败才降级）

| 级别 | 手段 | 适用 | 成本 |
|---|---|---|---|
| **L1** | **数据接口直取**（找到页面背后的 XHR/API） | 首选。政务站多数是前后端分离，HTML 只是壳 | 最低，纯 HTTP |
| **L2** | **Playwright 无头浏览器**（真实 Chromium 渲染 + 抓 XHR） | L1 找不到接口时 | 中，需 10–20s |
| **L3** | **agent-browser CLI** | L2 被环境限制 | 中 |
| **L4** | **内置 Chromium `--dump-dom`** | 兜底，拿渲染后 DOM | 中 |
| **L5** | **WebSearch 检索项目全名 + 字段词** | 只要字段不要全文（如"XX项目 截止时间"） | 低，但可能拿到二手转载 |
| ❌ | ~~直接放弃写"未披露"~~ | **禁止** | — |

**一键脚本**：`python3 references/fetch-rendered.py <URL>`
自动按 L1→L4 降级，输出 `title / publish / expiredAt / budget / deadline / qualifications / text / via`。

## 二、政采云（`zfcg.czt.zj.gov.cn`）实战档案

这是最重要的一个源，也是最坑的一个，单独记录。

### 2.1 真相：正文不在 HTML 里

- 详情页 `luban/detail?parentId=...&articleId=...` 的 HTML 有 **3.2 MB**，但 `body.innerText` 只有 **446 字**（页眉 + 面包屑 + "公告进度"四图标 + 页脚）。
- 即使跑真实 Chromium、等 12 秒、`networkidle`（该站有长轮询，**永远不 idle，用它会超时**），正文依然为空。
- **原因**：正文由 XHR 异步取回后注入，且不在 iframe 内。

### 2.2 正确的接口（L1，推荐）

```
GET https://zfcg.czt.zj.gov.cn/portal/detail?articleId={articleId}
Referer: https://zfcg.czt.zj.gov.cn/
```

- `articleId` 从详情页 URL 取，**注意保留 URL 编码**（`%3D` 即 `=`，也可直接传解码后的 `==`）。
- 返回 JSON：`result.data`
- **关键字段**：

| 字段 | 含义 | 用途 |
|---|---|---|
| `content` | **正文 HTML（完整）** | 提取预算、截止、开标、资质、联合体 |
| `title` / `projectName` / `projectCode` | 标题 / 项目名 / 编号 | 去重、反向搜结果公告 |
| `publishDate` | 发布时间（毫秒时间戳） | `NEW` 标记 |
| **`expiredAt`** | **过期时间** | ⭐ **直接判活单/死单，比什么都可靠** |
| `expireFlag` | 过期标志（0/1） | 同上 |
| `author` | 发布方（多为代理机构，**不是采购人**） | ⚠️ 别当成采购人写进日报 |
| `attachmentList` | 附件（招标文件 PDF/DOC） | 正文缺字段时下载正文附件 |
| `dynamicNodeLinkList` | **栏目导航节点**（采购意向/采购公告/结果公告/合同公告） | 🔴 **这不是本项目进度！** 路桥误报就是把这里读成了"还在采购公告阶段" |

### 2.3 实测样本（路桥青龙浦，2026-11-03 验证）

```
via: zcy-portal
publish:      2026-06-29 16:06
expiredAt:    2026-07-06T15:59:59Z   ← 抓取时早已过期 4 个月
budget:       50万元（预算价 50万 / 最高投标限价 50万元）
deadline:     2026-07-22 14:00
projectCode:  ZJWR－WLCG－2026－007
consortium:   False（不允许联合体）
正文:         5091 字
```

> 对照日报当时的写法：`预算：未披露`、`截止：未披露（以政采云公告为准）`、状态 `进行中`。**全部是抓取失败导致的假象**。

### 2.4 另一个可读版式（备选）

```
https://zfcg.czt.zj.gov.cn/innerUsed_noticeDetails/index.html?noticeId={noticeId}
```
该版式正文是服务端渲染的，WebFetch 可直接读到（宁海县结算审核项目的合同公告即从此处取到）。但 `noticeId` 与 `articleId` 不是一回事，需从列表页获得。

### 2.5 L1 接口分支：何时优先走、何时降级（2026-11-03 新增）

- **何时优先走接口**：只要拿到 articleId——来自详情页 URL（`.../portal/detail?articleId={id}` 等含 `articleId=` 参数的链接），或**列表页命中时当场留存**（见信源清单 §〇 硬规矩）——就先打 L1 接口，不要先开渲染链。一次返回正文 + `expiredAt` + `budget` + `deadline`，判死活所需字段全齐。
- **何时降级到渲染页**：articleId 无法取得（列表页只给标题、WebSearch 结果不带参数）→ 按 §一 链路 L2 Playwright / L3 agent-browser / L4 dump-dom 依次降级；仍拿不到再 L5 检索回落。
- **断链定性**：列表页只记标题不记 articleId 导致的正文取不到，**视为抓取失败而非"未命中"**——须按 §四 留痕，不得当成"查无此单"处理。实证：2026-11-03 温岭一院 11 月采购意向（11-03 发布），未留 articleId，后续 3 轮检索均取不到品目，前瞻窗口断链。

## 三、通用反爬要点（各站通吃）

### 3.1 别用 `networkidle`
政务站普遍有埋点/长轮询/心跳请求，`wait_until="networkidle"` **大概率超时**（实测 90 秒必失败）。用 `domcontentloaded` + 显式 `wait_for_timeout(8000)`，或 `wait_for_selector` 等目标元素。

### 3.2 证书链问题要忽略
多个政务站证书链不完整（政采云实测 `ERR_CERT_AUTHORITY_INVALID`）：
- Playwright：`new_context(ignore_https_errors=True)`
- Chromium：`--ignore-certificate-errors`
- Python urllib：`ssl.CERT_NONE`

> 日报只读取公开公告，不涉及登录与提交，忽略证书可接受。

### 3.3 带上像人的请求头
最低配置：真实 Chrome UA + `Referer`（指向该站首页）。多数政务站不校验 UA 白名单，但空 UA / `python-urllib` 容易被拦。

### 3.4 正文可能在 iframe
渲染后遍历 `page.frames`，取 `innerText` 最长的那个 —— 不要只看主 frame。

### 3.5 表格字段要按"表头对齐"取，别用关键词窗口
公告预算多为表格：
```
标项 | 采购内容 | 单位 | 数量 | 预算价 | 最高投标限价 | 服务期
1    | XXX项目  | 项   | 1    | 50万   | 50万元         | 一年
```
去标签后成了 `...项\n1\n50万\n50万元\n一年`。用"预算价"往后找第一个数字会**吃错**（把数量 1 和 50万 拼成 150万，实测踩过）。
正确做法：定位表头行 → 按列名顺序 → 在数据行取对应位置；或要求匹配值**整行都是金额形态**（`fetch-rendered.py` 已如此实现）。

### 3.6 附件往往是真信源
正文常写"详见采购文件"。`attachmentList` 里的 PDF/DOC 才是完整资格条件与评分办法。正文关键字段缺失时，**下载附件再提取**（`pdftotext` 已在环境内）。

## 四、当抓取仍然失败时

**允许**的降级：
1. 用 `WebSearch` 检索「项目全名 + 截止时间 / 预算金额 / 结果公告」——第三方转载有时带原文片段（但**标注为二手，且必须能落到一手链接**）；
2. 换版式（如政采云 `innerUsed_noticeDetails`）；
3. 找附件。

**不允许**：
- ❌ 写"截止：未披露（以 X 公告为准）"——这是**把核验责任外推给读者**，等于没做；
- ❌ 在预算与截止双缺的情况下仍标 `进行中` 进板块一（`check-dashboard.js` 5c 会 FAIL）；
- ❌ **静默跳过**——不写试过什么手段，等于无法复现。

**必须**：在当日「运行记录」里留一行，写清**试过哪几级、失败原因**：
```
路桥青龙浦绩效评价 — L1 接口 expiredAt=2026-07-06 已过期，判死剔除（原误报，见 §七）
某天台项目 — L1 无接口 / L2 渲染后正文 0 字 / L3 缺 agent-browser / L4 DOM 空 → 判「无法核验」剔除
```

## 五、工具可用性（2026-11-03 实测）

| 工具 | 状态 | 备注 |
|---|---|---|
| Playwright（Python） | ✅ 1.58+ | `from playwright.sync_api import sync_playwright` |
| Playwright（Node） | ✅ 1.58.1 | `npx playwright` |
| Chromium | ✅ `/usr/bin/chromium`（Chrome 144） | `--headless=new --dump-dom` |
| agent-browser | ✅ `/root/.nvm/.../bin/agent-browser` | CLI |
| jinja2 | ⚠️ **是模板引擎，不是浏览器** | 名字易混；它无法渲染 JS 页面。若要"服务端渲染"，那是本地渲染 HTML **字符串**，不解决反爬 |
| browser-use | ❌ 未安装 | 需要时 `sudo pip3 install browser-use` |

> 补充：如果链路全部失败且**必须**拿到，可用「内置浏览器面板」人工打开一次（cookie 会持久化），之后用同一会话抓取。
