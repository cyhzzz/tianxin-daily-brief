> 本规范用于天信每日日报「板块一 台州本地商机」的逐条加工。目标：把零散的招标/采购公告，转化为天信**可直接判断是否跟进**的结构化情报。本规范为通用招投标商机监测方法论，待选定专家（ex_sSgdUk3cOb5O / ex_t3AfWD4XzarF）工作流到位后对齐替换。

## 〇、天台县专项优先（本所驻地）

天台县是天信驻地，商机优先级最高，规则如下：

1. **检索必须主动覆盖天台县**：除各信源常规检索外，天台县须**单独走三个本地入口**（详见 references/信源清单.md 第八、九、十条）：

   并叠加 `天台` 关键词（如 `财务审计 竣工决算 中介机构 天台`、`天台 代理记账 采购`、`天台 会计服务 采购`、`天台县 框架协议 征集公告`），不得遗漏本县单。
2. **天台县条目一律置顶**：无论金额大小，板块一先列「天台县专项」子区，并加「天台县」标识。
3. **真正的入口是「框架协议库 + 平台公告」，不是部门**（2026-10-30 核实修正）：

## 〇之二、核心校验门禁（原⼦核验 · 2026-11-03 新增，硬性前置）

> **为什么有这一节**：2026-11-03 日报误报「路桥青龙浦水质提升及生态修复项目绩效评价服务」。该项目实际 **2026-07-23 已发中标结果公告、2026-08-20 已签合同**（中标方生态环境部南京环境科学研究所，48.6 万元），却被当成"进行中可独立投活单"写进板块一和今日提示，并被推送到三个通道。详见 §七 事故复盘。
>
> 根因不是"没查到"，而是**在关键字段全为「未披露」的情况下仍然判定其为活单**。故增设本节：**任何商机在写入日报前，必须过完整原子核验，不得以"以公告为准"代替核验。**

### 判定公式

一条商机只有同时满足下列全部条件，才允许进入板块一：

1. **状态是"可投"**：公告类型 ∈ {采购公告/招标公告/征集公告/竞争性磋商/询价/竞价}，且**未出现**结果公告、中标（成交）公告、候选人公示、合同公告、废标/流标/终止公告；
2. **时间未过**：投标（响应）截止时间或开标时间 **> 现已**（仅"发布日期在 7 天内"**不足以**判定为活单）；
3. **关键字段取到值**：**预算/最高限价**、**截止时间** 两项至少取到一项**非「未披露」**的真实值。

> 三项只要有任意一项无法证实 → **判定为「核验未通过」，整条剔除，不写进板块一，也不写进今日提示**。
> 被剔除的条目可在「运行记录」中留一行（例：`路桥青龙浦绩效评价 — 核验未通过（已中标/合同公告 2026-08-20），剔除`），**不得进入看板正⽂**。

## 三、商机评分（四维标签法）

不输出分数数字，用 高 / 中 / 低 三档，取四者综合：

- **金额**：>50万=高，10-50万=中，<10万=低
- **匹配度**：可独立投=高，需联合=中，不匹配=低（天台县单默认可独立投=高）
- **紧迫度**：近 2 天发布（NEW）或 ≤7 天截止（急）=高，30 天内=中，更久=低
- **属地**：天台县=高，**台州其他县市区=中高**，**周边县市（宁海/新昌/嵊州）=中（可投性未定）**，浙江其他=低

排序：高>中>低。例：交投集团 136万/年 + 需联合 + 招标中 → 金额高·匹配中·紧迫中 = **高**（值得重点盯）；天台县司法局决算 3万 + 可独立投 + 近2天发布 → 金额低·匹配高·紧迫高·属地高 = **中·优先**（本县单，应主动触达）；三门中介竞价 3万 + 可独立投 + 已成交 → 金额低·匹配高·紧迫低·属地中 = **中**（作模式参考）。

### 根因（按链条逐环）

1. **入口给了"半截信息"**：命中来源是政采云 `luban/detail` 详情页，页面**正文由 JS 渲染**，WebFetch 只拿到标题 + 公告进度条 + "获取采购文件"按钮。此时**预算与截止都取不到**。
2. **把"取不到"合理化成了"未披露"**：字段表允许标"未披露"，于是这条被判为"信息不全但可报"，**而没有触发"信息不全即不可信"的反向判断**。
3. **误读了页面上的进度条**：页面同时显示「采购意向公开 / 采购公告 / 结果公告 / 合同公告」四个节点（这是政采云的**栏目导航**，不是"本项目已走到哪一步"的进度），被当成"还在采购公告阶段"。**这是最关键的误判点。**
4. **没做定标反向检索**：规则里写了"已定标/过期一律剔除"，但**只对浙里招标/阳光采购强调了要过滤**，对政采云条目没有强制"搜结果公告"的动作，导致制度有、动作无。
5. **标签自相矛盾未被拦下**：`进行中` + 预算未披露 + 截止未披露 三件套本来就不成立，但自检脚本只验数字与占位符，验不到"语义空洞"。

### 修复（已落地到本规范 §〇之二）

- **V1 结果/合同公告反向检索**设为强制动作，命中即剔除；
- **判定公式**要求"预算/截止至少一项有实值"，直接封死"全未披露也能入报"的口子；
- **成熟度标记** `✔核验 / ⚠待核 / ✖剔除` 强制上书，让负责人看得到可信度；
- **明确废弃**"截止：未披露（以政采云公告为准）"这种把核验责任外推给读者的写法；
- 把「政采云详情页四个节点 = 栏目导航」写进 §八 已知陷阱，避免再次误读。

### 纪律升级

- 日报写"进行中"三个字，背后必须有**一个能复现的截止时间或开标时间**；拿不出就不许写。
- 宁可板块一少一条，不可多一条假的。**空着不丢人，报错单会让人白跑一趟。**

## 八、已知陷阱（实战踩坑登记）

| 陷阱 | 表现 | 正确做法 |
|---|---|---|
| **政采云详情页"公告进度"四节点** | 页面显示「采购意向公开 / 采购公告 / 结果公告 / 合同公告」四个图标 | 这是**全站栏目导航**，与本项目进度无关。判死必须靠 V1 搜结果公告，不能看这个条 |
| **政采云 `luban/detail` 正文 JS 渲染** | WebFetch 只得标题，正文空白 | 走 `innerUsed_noticeDetails/index.html?noticeId=` 版式，或检索项目全名+"截止时间"，或站内下载采购文件 |
| **中标价被当成预算** | 结果公告里"中标（成交）金额 486000 元" | 那是**成交价**，不是预算/限价；回填须注明口径与日期 |
| **跨地级市误判属地** | 嵊州/新昌属**绍兴市**、宁海属**宁波市**，不是台州 | 属地写到县级，并注明所属地级市；对应信源也不同（见 §〇之三） |
| **省级平台与地市平台重复收录** | 同一条单在 `ggzy.tzztb.zjtz.gov.cn`、`ggzy.zj.gov.cn`、阳光采购都出现 | 按项目名称去重，保留信息最全的那条链接 |
| **"采购意向"被当成"采购公告"** | 采购意向只说明"预计 X 月采购"，无截止时间 | 意向单可作**线索**列入（标"意向"），但**不得标 `进行中`**、不参与活单计数 |

## 九、红线
- 不替天信向任何业主承诺中标或关系。
- 国企大单的证券资格门槛必须如实标注，不得暗示天信可独立承接。
- 所有商机仅作情报提示，对外动作须经负责人（及事务所）人工复核。
- **不得以"未披露"掩盖未核验**：预算与截止双双未披露的条目一律不得进入板块一（见 §〇之二）。
