# 招标商机处理规范（专家级）

> 本规范用于天信每日日报「板块一 台州本地商机」的逐条加工。目标：把零散的招标/采购公告，转化为天信**可直接判断是否跟进**的结构化情报。本规范为通用招投标商机监测方法论，待选定专家（ex_sSgdUk3cOb5O / ex_t3AfWD4XzarF）工作流到位后对齐替换。

## 〇、天台县专项优先（本所驻地）

天台县是天信驻地，商机优先级最高，规则如下：

1. **检索必须主动覆盖天台县**：除各信源常规检索外，天台县须**单独走三个本地入口**（详见 references/信源清单.md 第八、九、十条）：
   - 天台县政府门户·公共资源交易栏目 `www.zjtt.gov.cn/col/col1659806/`（WebFetch 可直抓）
   - 天台县阳光招采平台 `tiantai.hibidding.com`（JS 站，WebSearch 限定域名）
   - 浙江省公共资源交易服务平台 `ggzy.zj.gov.cn` 叠加 `天台` / `台州` / `审计`
   并叠加 `天台` 关键词（如 `财务审计 竣工决算 中介机构 天台`、`天台 代理记账 采购`、`天台 会计服务 采购`、`天台县 框架协议 征集公告`），不得遗漏本县单。
2. **天台县条目一律置顶**：无论金额大小，板块一先列「天台县专项」子区，并加「天台县」标识。
3. **真正的入口是「框架协议库 + 平台公告」，不是部门**（2026-10-30 核实修正）：
   - 🔑 **天台县会计审计、预算绩效评价咨询服务框架协议采购**（2025-2026 年度，`TTCG-2025-KJ002`）是天台县本级会计/审计/绩效单的**总入口**，采购人范围「联动区划下所有采购单位」。**天信已在库**（2025-03-31 入围，第三方标讯；更早 2023-2024 年度预算绩效管理服务开放式框架协议亦曾入围）——**请负责人确认库内状态**。
   - ❌ 删除"常监测业主＝天台县司法局/机关事务中心/各乡镇"的旧写法：这类单由业主在平台公开发布、公开竞价或**库内选择**，**不存在靠对接部门拿单的通道**；日报不得给出"对接某部门即可获单"的暗示。
   - 中介服务网天台分区（`zjfw.zwfwb.zjtz.gov.cn`，编号前缀 `ttzj-`）作补充即可：天台在该平台**以工程造价类为主**，审计类频次明显低于三门县，不按三门频次预期。
4. **匹配默认友好**：天台县行政事业与中介竞价单，天信通常 ✅ 可独立投（同资质），优先提示对接路径。若命中**框架协议新一轮征集公告**，不计金额、直接置顶为最高优先级。

## 一、结构化解析（字段表）

从公告原文逐项提取，原文未写的字段标「未披露」，严禁推算或编造。

| 字段 | 说明 | 示例 |
|---|---|---|
| 项目名称 | 公告标题中的标的核心 | 台州市交通投资集团 2026-2028 年度财务报表审计、季度审阅 |
| 采购人/业主 | 谁发包 | 台州市交通投资集团有限公司 |
| 采购类型 | 政府采购·行政事业 / 国企采购 / 中介竞价 | 国企采购 |
| 预算/最高限价 | 金额或费率上限 | 136 万元/年 |
| 服务期 | 合同年限 | 2026-2028（三年） |
| 报名/投标截止 | 关键时间点 | 未披露（以招标文件为准） |
| 开标时间 | 若有 | 未披露 |
| 资质门槛 | 是否要求证券资格、执业证书、年限 | 需证券服务业务备案 + 10 年 CPA 经验 |
| 地区 | 精确到县 | 椒江区（市本级） |
| 原文链接 | 来源 | ggzy.tzztb.zjtz.gov.cn/... |
| 发布时间 | 公告日 | 2026-10-15 |

## 二、资质匹配规则

**天信画像**：浙江台州天台县县城中小型所；具备审计、资产评估、税务、代理记账、财务咨询资质；**暂无证券服务业务备案资格**。

| 结论 | 判定 | 处置话术 |
|---|---|---|
| ✅ 可独立投 | 行政事业代理记账/财务审计/绩效评价/竣工决算、中介竞价小单（天台及周边县） | 天信可独立承接，提示对接路径 |
| 🔶 需联合/下级 | 台州市属国企年审大单（通常要证券资格） | "可联合大所，或争取其子公司/下级公司审计" |
| ⚪ 暂不匹配 | 明确要证券资格且天信无法借力 | 仅作情报留存，不误导可投 |

## 三、商机评分（四维标签法）

不输出分数数字，用 高 / 中 / 低 三档，取四者综合：

- **金额**：>50万=高，10-50万=中，<10万=低
- **匹配度**：可独立投=高，需联合=中，不匹配=低（天台县单默认可独立投=高）
- **紧迫度**：近 2 天发布（NEW）或 ≤7 天截止（急）=高，30 天内=中，更久=低
- **属地**：天台县=高，台州其他县=中，浙江其他=低

排序：高>中>低。例：交投集团 136万/年 + 需联合 + 招标中 → 金额高·匹配中·紧迫中 = **高**（值得重点盯）；天台县司法局决算 3万 + 可独立投 + 近2天发布 → 金额低·匹配高·紧迫高·属地高 = **中·优先**（本县单，应主动触达）；三门中介竞价 3万 + 可独立投 + 已成交 → 金额低·匹配高·紧迫低·属地中 = **中**（作模式参考）。

## 四、跟进建议模板

每条 1 句，含三要素：**谁可对接 + 下一步动作 + 关键时间点**。
- 例（可独立投）：「天台县 XX 局代理记账框架协议，建议所里先入库政采云，关注下期征集公告。」
- 例（需联合）：「交投集团年审 136万/年招标中，天信无证券资格，建议联系中证天通/大信等中标所探讨分包或下级公司审计合作。」

## 六、红线
- 不替天信向任何业主承诺中标或关系。
- 国企大单的证券资格门槛必须如实标注，不得暗示天信可独立承接。
- 所有商机仅作情报提示，对外动作须经负责人（及事务所）人工复核。
